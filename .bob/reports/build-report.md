## State Machine

```
PENDING
  └─► OPTIONS_READY   (after options_generator runs)
        └─► SELECTED        (after user selects an option)
              └─► ASSETS_GENERATING  (after asset_finisher starts)
                    ├─► ASSETS_READY     (safety gate passed, budget OK)
                    └─► PENDING          (safety gate failed — retry)
                          └─► APPROVED       (human review sign-off)
                                └─► PUBLISHED      (DAM + notifications sent)
```

## Key Technical Decisions

| Decision | Choice | Reason |
|----------|--------|--------|
| Image generation API | `generate_content` + `response_modalities=["IMAGE"]` | Gemini SDK v2 — `generate_images` removed |
| Async test mode | `@pytest.mark.asyncio` on every async test | `asyncio_mode=strict` in pytest config |
| Firestore collection | `agent_props` | Avoid collision with app-backend `app_props` |
| Kafka events | Strict no-op when `KAFKA_ENABLED=false` | Never raise errors in test/local env |
| Platform adapter | 3-tier: Stub → LocalADK → AgentEngine | Progressive enhancement pattern |
| Safety check | Cloud Vision SafeSearch + Gemini vision fallback | Defence in depth |
| Budget guardrail | Hard abort + status record | Prevents runaway spend |
